# PULSE — стартовый интерфейс

Стартовый frontend-прототип социальной сети PULSE на React + TypeScript + Vite.

## Что уже есть
- Адаптивный интерфейс с нижней навигацией: Главная, Чаты, Создать, Видео, Профиль.
- Три темы: светлый минимализм, премиум (чёрный/золото), уютная.
- Лента публикаций, истории, карточки постов, лайки и сохранение (демо-состояние).
- Демонстрационные экраны чатов, видео и профиля.
- Окно создания фото, видео, истории, текста, группы и канала.

## Запуск локально
Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

## Важно
Это только стартовый frontend-прототип. Реальная авторизация, база данных, загрузка медиа, сообщения, звонки, модерация и серверная логика ещё не подключены. Не добавляйте секретные ключи в клиентский код. Подключение Supabase и Cloudflare следует выполнять отдельным безопасным этапом.

Внешние фотографии загружаются с Unsplash и требуют подключения к интернету.
